## 💡 为什么选择 OneKey？

1. **零第三方运行时依赖**：不捆绑庞大的配置库（如 Cloth Config），不依赖复杂的统一抽象层，双端 Jar 包仅 ~120 KB，纯净启动零开销。
2. **双加载器原生对齐**：使用相同的核心逻辑内核，在 Fabric 与 NeoForge 平台上享受 100% 完全一致的性能与交互。
3. **0ms 乐观 UI 响应**：按下整理按键瞬间，客户端即刻通过射线置换展现整理效果并播放音效，服务端权威异步校准，告别网络卡顿感。
4. **手势操作深度进化**：吸收 MouseTweaks / ItemScroller 长处，支持 **Shift + 左键拖拽滑动扫掠**、**右键画线重复放置**与**滚轮单件进出微调**，配平合成矩阵或清空箱子只需鼠标划动一圈。
5. **快捷栏由你决定**：底部 9 格快捷栏（0..8）是否参与整理与鼠标手势，由设置里的独立开关控制（默认开启）；关掉就恢复「快捷栏绝对不动」的保守模式，加锁槽位则永远不参与。
6. **槽位锁定与视觉高亮**：按住 `Alt + 左键` 即可随时锁定珍贵物品槽位，锁定槽位在整理与存入时受到绝对保护，数据按世界存档独立持久化。
7. **看哪存哪与智能防污染**：按下 `B` 键即可将战利品智能并入准星锁定的目标容器，且背包全新物品只进焦点容器，周围分类箱绝不被塞入杂物。

## 🎮 默认快捷键与手势

| 快捷键 / 手势 | 动作名称 | 适用场景 | 功能说明 |
|:---:|:---:|:---:|---|
| <kbd>R</kbd> | **一键整理** | 容器/背包打开时 | 先合并同类堆叠，再按「分类 → 名称 → 数量」排序，空格后置；快捷栏是否参与见设置开关，锁定格永远不动 |
| <kbd>V</kbd> | **快速堆叠** | 靠近容器或任何时候 | 将背包物品并入同类堆叠：优先准星瞄准的容器，其余按距离扫描；不会向空槽塞陌生物品 |
| <kbd>B</kbd> | **一键存入** | 靠近容器或任何时候 | **看哪存哪**：准星瞄准的容器（或已打开的容器界面）作为唯一目标倾倒物品；未瞄准时仅并入已有同类堆叠 |
| <kbd>K</kbd> | **打开设置** | 任何游戏界面 | 呼出 OneKey 原生 8 行配置界面，直观调整全部 8 项功能开关与参数 |
| <kbd>Alt</kbd> + **左键** | **槽位锁定** | 悬停任意槽位 | 切换槽位锁定状态（0..35 含快捷栏均可加锁）；锁定后显示琥珀色描边高亮，免受一切整理、存入与手势影响 |
| <kbd>Shift</kbd> + **左键拖拽** | **滑动扫掠转移** *(v1.1)* | 容器/背包打开时 | 按住 Shift 划过槽位连续快速移动到对侧；空手触发，加锁槽位与产物槽严格保护，支持工作台扫掠收回原料 |
| **右键拖拽划动** | **画线重复放置** *(v1.1)* | 容器/背包打开时 | 光标持物时按住右键划过槽位连续投放；多次划过同一槽位持续追加，单次划圈轻松配平合成矩阵 |
| <kbd>Shift</kbd> + **双击** | **批量同类转移** | 悬停任意槽位 | 300ms 内双击某槽位，自动搜寻同侧所有同类未锁定物品移入对侧容器 |
| **滚轮上滚 / 下滚** | **单件微调进出** | 悬停任意槽位 | 向上滚动抓取 1 件补充当前格，向下滚动移出 1 件到对侧；支持自然滚轮反转与光标持物向下微调 |

> 提示：所有快捷键均可在原版「选项 → 控制 → 按键绑定 → OneKey」中自由修改。

## ⚙️ 图形设置界面

按下 <kbd>K</kbd> 键即可呼出游戏内原生设置界面（完全基于 Minecraft 原生 UI 构建，无需额外安装任何库，自适应所有 GUI 缩放比例）：

| 设置项 | 默认值 | 作用与交互说明 |
|---|:---:|---|
| **整理开关与规则** | 开启 (`分类排序`) | 支持切换「分类排序」、「名称排序」与「数量降序」三种规则 |
| **快速堆叠参数** | `6` 格 (档位 2/4/6/8) | 附近容器扫描半径，受原版方块实体交互距离保护 |
| **整理包含快捷栏** | 开启 (`true`) | 关闭后 `R` 整理与 `B`/`V` 快速堆叠只作用于主背包 9..35，快捷栏 0..8 绝对不动 |
| **手势影响快捷栏** | 开启 (`true`) | 关闭后滚轮微调、`Shift + 双击` 与 `Shift + LMB 扫掠` 只对主背包生效 |
| **准星瞄准优先** | 开启 (`true`) | 按 `B`/`V` 时先把准星指向的箱子锁定为目标（看哪存哪）；关闭后按几何距离存入 |
| **合并同类堆叠** | 开启 (`true`) | 按 `R` 时先把散落的同类堆叠并成满堆（同物品且同组件）再排序；关闭后只排序不合并 |
| **智能分类防污染** | 开启 (`true`) | 背包里的全新物品只会进入你瞄准/打开的容器，周边分类箱不会被塞入陌生物品 |
| **Shift左键扫掠转移** | 开启 (`true`) | 允许按住 Shift + 左键划过槽位连续快速转移物品（支持工作台材料快速收回） |
| **右键划动重复放置** | 开启 (`true`) | 允许按住右键拖拽时多次经过同一槽位持续追加放置物品，惰性接管且保护单点 |
| **滚轮方向反转** | 关闭 (`false`) | 反转滚轮微调方向，原生适配 macOS 触控板自然滚动 |
| **持物滚轮微调** | 开启 (`true`) | 光标抓着物品悬停槽位时，向下滚轮即可向当前槽位精准投放 1 件持物 |

## 📦 安装与要求

### 运行环境
- **游戏版本**：Minecraft 26.3
- **运行环境**：Java 25（Temurin 25 / Oracle 25 / OpenJDK 25）
- **加载器支持**：
  - **Fabric**：Fabric Loader >= 0.20.1，Fabric API >= 0.165.2+26.3
  - **NeoForge**：NeoForge >= 26.3.0.101

### 服务端与多人游戏支持
- **单人模式**：完全开箱即用，所有功能完整生效。
- **多人服务器**：推荐在服务端与客户端**双端同时安装**。服务端权威保证物品绝对守恒，杜绝任何刷物与丢物漏洞；客户端乐观预测提供 0ms 顺滑手感。

## 🛠️ 从源码构建

本项目采用 Gradle 多模块架构（`common` 纯逻辑内核 + `fabric` 平台壳 + `neoforge` 平台壳），构建依赖仓库内建脚本：

```bash
# 克隆代码仓库
git clone https://github.com/Roland114514/OneKey.git
cd OneKey

# 执行全量多模块编译与单测（使用自带 JDK 25 脚本）
bash scripts/with-jdk25.sh clean build

# 单独启动 Fabric 客户端测试
bash scripts/with-jdk25.sh :fabric:runClient

# 单独启动 NeoForge 客户端测试
bash scripts/with-jdk25.sh :neoforge:runClient
```

构建成功后产物位于：
- `fabric/build/libs/onekey-fabric-1.1.1.jar`
- `neoforge/build/libs/onekey-neoforge-1.1.1.jar`

## ⚠️ 已知限制

- **槽位锁定按容器类型记录**：锁定键是菜单类型（如 `minecraft:generic_9x3`），因此同尺寸的箱子/木桶会共享同一组锁定槽位；按容器坐标隔离排在后续规划。
- **扫描半径上限**：快速堆叠受原版容器交互距离限制（`stillValidBlockEntity` 约 8.5 格），配置里填写更大半径不会生效，设置界面档位上限为 8。
- **快速堆叠暂只豁免背包锁定槽**：外部容器内被 `Alt+左键` 锁定的槽位，批量存入（`B`/`V`）时尚未跳过（整理 `R` 已豁免），计划随后续「按坐标锁定」一并支持。
- **末影箱需打开界面**：末影箱没有世界坐标，未打开界面时不会进入范围扫描。
- **整理与滚轮只在纯存储容器生效**：箱子/木桶/末影箱/发射器/投掷器/漏斗/潜影盒；熔炉、工作台、铁砧、交易等界面一律只整理玩家背包，避免搬动结果槽。
