# OneKey · 轻量操作优化 (Inventory Optimization)

**装完就能少点几百次鼠标！**
面向 **Minecraft 26.3（Java 25）** 的超轻量、零依赖现代背包收纳优化模组，原生支持 **Fabric** 与 **NeoForge**。

---

## ⚡ 为什么选择 OneKey？

- **0 运行时依赖**：不到 100 KB，不需要 Cloth Config 或 Architectury 等庞大依赖，启动速度飞快，不增加任何卡顿；
- **0ms 整理手感**：整理按下的瞬间，客户端本地即刻展现重排视觉与音效，随后与服务端无缝校验对齐；
- **底部快捷栏绝对保护**：底部 9 格快捷栏（0..8）严格**不参与**背包整理与堆叠，保证您的主手工具、武器与火把安全留在原位；
- **槽位锁定系统**：`Alt + 左键` 即可随时锁定/解锁任意槽位，带醒目红框高亮，锁定槽位在任何整理或转移中享有绝对豁免权，且按存档世界独立保存；
- **附近容器快速堆叠与存入**：无需繁琐打开一个个箱子，一键智能把背包战利品合并进周围 6 格范围内容器；
- **双端严格防作弊**：服务端权威校验物品总数守恒，两阶段贪心合并，绝不丢物、绝不刷物。

---

## 🎮 默认按键与手势

| 快捷键 | 功能 | 说明 |
|:---:|:---:|---|
| **R** | **一键整理** | 开启容器时智能整理，按「分类 → 名称 → 数量」排序 |
| **V** | **快速堆叠** | 自动合并背包物品进周围 6 格内容器的现有堆叠 |
| **B** | **一键存入** | 将背包符合条件的整叠物品存入周围容器 |
| **K** | **设置界面** | 呼出游戏内原生配置菜单（无需任何外部 UI 库） |
| **Alt + 左键** | **槽位锁定** | 锁定/解锁槽位，红框视觉高亮保护 |
| **Shift + 双击** | **批量转移** | 双击槽位快速将同侧所有同类物品移入对侧容器 |
| **鼠标滚轮** | **单件微调** | 上滚从对侧抓取 1 件补充，下滚移出 1 件到对侧 |

*所有按键均可在原版「选项 → 控制 → 按键绑定 → OneKey」中自由修改。*

## 📥 安装说明

- **Minecraft 版本**：`26.3`
- **Java 版本**：`25`
- **支持平台**：
  - **Fabric**：需 Fabric Loader >= 0.20.1，Fabric API >= 0.165.2+26.3
  - **NeoForge**：需 NeoForge >= 26.3.0.101
- **服务端推荐**：本模组支持单人与多人。在多人服务器中，建议服务端与客户端双端安装以获得最佳安全防作弊与低延迟同步体验。
