# OneKey v1.0.3 Release Notes (Minecraft 26.3 · Java 25)

🎯 **OneKey v1.0.3「整理即合并」维护版发布！**
一键整理现在会先把散落的同类堆叠并成满堆，再按「分类 → 名称 → 数量」排序。
面向 Minecraft 26.3 的现代化、极轻量、零第三方运行时依赖操作优化模组，原生支持 Fabric 与 NeoForge 双加载器。

## 🎯 v1.0.3 更新摘要

### 新增

- **整理时自动合并同类堆叠**：背包里同一个物品散在多个格子（例如 16 个橡木楼梯在一格、10 个在另一格）时，按 `R` 现在会**先合并再排序** —— `16 + 10 → 26 + 空`、`40 + 40 → 64 + 16`，余量自动顺延到下一格。
- **严格同物品判定**：按 `isSameItemSameComponents` 比较，附魔不同、耐久不同、装着不同物品的潜影盒、药水效果不同的堆叠**绝不会**被合并。
- **外部容器同样生效**：整理箱子 / 木桶 / 潜影盒时，容器内部散落的同类堆叠也会被并成满堆。
- **新增设置项「合并同类堆叠」**（`sort.mergeStacks`，默认开启）：`K` 打开设置界面可一键关闭，恢复「只排序不合并」的旧行为。
- **快捷栏参与权交给玩家**：新增「整理包含快捷栏」`sort.includeHotbar` 与「手势影响快捷栏」`gestures.includeHotbar` 两个开关（**默认开启**），关掉即恢复 v1.0.2 的「快捷栏绝对不动」行为。
- **快捷栏可加锁**：`Alt + 左键` 现在可为 0..35 任意槽位加锁（含快捷栏），锁定槽位在整理、堆叠、手势中永远不参与。

### 修复 / 加固

- **锁定槽位保护不变**：合并阶段同样不触碰锁定槽位（既不作来源也不作目标）；快捷栏是否参与由开关决定，盔甲与副手永不被触碰。
- **总数守恒**：合并只重分配数量、不搬运物品本体，物品总数恒定（有单元测试锁死）。
- **客户端乐观排序与服务端执行逻辑镜像**，不会出现「本地看着合并了、服务端没合并」的双重反馈。

### 兼容性

- 协议版本保持 **2**（payload 结构未变）：1.0.2 与 1.0.3 **可以混合连接**，无需同时升级。
- 旧 `config/onekey.json` 缺少 `mergeStacks` / `sort.includeHotbar` / `gestures` 字段时按默认值处理，配置向后兼容。

### 测试

- 新增 `StackCondenserTest` 7 例（散堆合并、上限溢出顺延、不同物品不合并、锁定槽隔离、总数守恒、空槽忽略、不可堆叠物品各自保留）。
- 新增 `InventorySlotsTest` 4 例（快捷栏包含规则、盔甲/副手永不参与、0..35 全部可加锁）。
- 双端测试合计 **104 例全部通过**（每端 52 例）。

## ✨ 核心特性

- ⚡ **一键整理 (`R`)**：先合并同类堆叠 → 按「分类 → 名称 → 数量」排序，空槽后置；
- 🚀 **0ms 视觉响应**：本地乐观置换瞬时反馈，服务端权威无缝校准；
- 🛡️ **快捷栏可控**：底部 0..8 是否参与整理与手势由设置开关决定（默认开启），加锁槽位永远免疫；
- 🔒 **槽位锁定 (`Alt + 左键`)**：琥珀色描边高亮保护，世界存档独立记忆；
- 🎯 **看哪存哪 (`B`)**：准星锁定容器或当前打开的界面作为唯一目标，分类箱不再被误塞；
- 📦 **附近容器快速堆叠 (`V`)**：自动扫描周围 6 格容器，严格物品守恒；
- 🖱️ **鼠标手势增强**：Shift 双击批量同类转移、滚轮单件进出微调；
- ⚙️ **原生零依赖设置菜单 (`K`)**：无须第三方 UI 库，可视化调节所有参数；
- 🔍 **智能冲突检测**：自动检测 IPN、Mouse Tweaks、Item Scroller 等并提示。
