## 🐛 v1.1.3 核心修复与加固

### 1. 连锁破坏方块距离校验导致高树与长隧道截断（关键）
- **根因**：1.1.2 在连锁破坏循环中对每一个目标方块都执行了 `player.isWithinBlockInteractionRange(targetPos, 1.0)`。原版玩家交互触及距离仅约 4.5~5.0 格，导致高达 20+ 格的巨型云杉/丛林树冠、向深处延伸的长隧道以及大型矿脉中超出 5.5 格范围的所有方块被全部跳过，发生“树砍一半”、“隧道截断”现象。
- **修法**：将距离校验重构为两级分层防护：
  1. **原点锚点校验**：进入连锁前，严格校验玩家是否触及原点方块（`player.isWithinBlockInteractionRange(originPos, 2.0)`），杜绝远程假包；
  2. **拓扑安全包络校验**：循环遍历目标方块时，校验相对原点方块的空间欧氏距离（`originPos.distSqr(targetPos) <= 36.0 * 36.0`），并确保目标位于世界边界内且已加载（`level.isLoaded(targetPos) && level.isInWorldBounds(targetPos)`），既杜绝跨未加载区块引发的服务端卡顿，又完美保证整棵高树与完整矿脉/隧道的挖掘。

### 2. 连锁过程中工具实时防爆刹车与损坏空手防作弊（安全）
- **根因**：原先的防爆检查只在破坏前检查了手持工具状态，未在循环的每次迭代中动态跟踪工具最新剩余耐久；当剩余耐久为 2 时破坏方块，工具耐久被扣减至 1 或 0（可能引发爆镐）；若工具彻底损坏变为空气，此前可能导致玩家空手继续破坏后续方块。
- **修法**：
  1. 在每次破坏目标方块前，动态获取主手最新工具状态；若初始持有有效工具但中途损坏变空，立即 `break` 终止连锁，绝不空手继续破坏；
  2. 启用防爆保护时，若工具最新剩余耐久 `<= 2`，立即 `break` 终止整条连锁，杜绝爆镐爆斧。

### 3. 保护玩家容器方块（箱子/木桶/潜影盒/漏斗等）
- **根因**：在 3x3 隧道或连锁模式下，若玩家在基地附近挖掘，可能不慎破坏包含大量物品的箱子或容器，导致数百组掉落物爆出或造成刷物品/容器丢失隐患。
- **修法**：在客户端预览与服务端破坏逻辑中统一跳过所有 `instanceof Container` 的方块实体（箱子、木桶、潜影盒、漏斗、发射器、熔炉等），绝对保障玩家存储设施安全。

### 4. ThreadLocal 掉落聚合异常安全性与双重泄露防护
- **根因**：掉落聚合捕获器使用 ThreadLocal 维护上下文，若因任何非预期异常或 Mod 拦截中断，可能有 ThreadLocal 残留风险。
- **修法**：在 `onBlockBroken` 的最外层 `finally` 中显式调用 `remove()` 清理所有挖掘与聚合 ThreadLocal，实现无条件零泄漏保底。

### 5. NeoForge 延迟破坏防切工具作弊与原点状态复核
- **根因**：NeoForge 端在 tick 间复核原点时，若恶意客户端利用微小时间差切换工具可能骗取附魔；且用 `.isAir()` 复核会在含水方块（破坏后为水）或沙子下落时误判失效。
- **修法**：
  1. 入队时快照记录触发瞬间的工具组件，并在复核时比对 `ItemStack.isSameItemSameComponents`，工具被调包则拒绝连锁；
  2. 原点复核改为确认方块不再是破坏前的方块（`!getBlockState(pos).is(state.getBlock())`），含水方块和落沙场景均可正常连锁。

### 6. 网络状态包模式与方块上限安全夹取
- **修法**：`ExcavatorStatePayload` 解码时对 `shapeId` 与 `maxBlocks` 进行严格范围夹取，非法枚举索引自动回落为 `VEIN`，`maxBlocks` 强制夹取在 `[1, 128]` 之间，防止发包注入异常。

## 📥 安装方式

1. 安装对应加载器（Fabric Loader ≥ 0.20.1 + Fabric API 0.165.2+26.3；或 NeoForge 26.3.0.101）；
2. 将对应 jar 放入 `mods/` 目录；
3. 单人游戏可只装客户端；多人服建议**服务端与客户端都装**，否则整理/堆叠/连锁破坏等操作不会有服务端配合（客户端会提示「服务器未安装 OneKey」）。

## ⌨️ 默认按键

| 按键 | 功能 |
|---|---|
| `R` | 一键整理（先合并同类堆叠，再按分类 → 名称 → 数量排序） |
| `V` | 快速堆叠（并入附近容器中同类堆叠） |
| `B` | 一键存入（准星看哪存哪，智能防污染） |
| `K` | 设置界面（4 个分页） |
| `Alt + 左键` | 锁定 / 解锁槽位 |
| `~`（按住） | 连锁破坏；按住 `~` + 滚轮切换「同类连通 / 1x2 矿道 / 3x3 隧道」 |

## 🔧 已知限制

- 槽位锁定按容器类型记录（如 `minecraft:generic_9x3`），同尺寸容器共享锁定槽位；
- 快速堆叠受原版交互距离限制（约 8.5 格），配置里填写更大半径不会生效；
- 快速堆叠暂只豁免背包内锁定槽，外部容器内被锁定的槽位尚未跳过（整理已豁免）；
- 末影箱需打开界面才会参与；
- 整理与滚轮只在纯存储容器生效（箱子/木桶/末影箱/发射器/投掷器/漏斗/潜影盒）。
