## 🎯 v1.0.2 更新摘要

本次为 **B 键快速存入重构版**：从「盲目扫描周围容器」升级为「看哪存哪 + 分类防污染」，并补齐对应 GUI 开关。

### 新增

- **准星射线目标锁定（看哪存哪）**：按 `B` / `V` 时沿视线射线检测（长度取原版方块交互距离：生存 4.5 / 创造 5 格），命中合法容器则本次操作**唯一锁定该容器**，周围箱子不参与；未命中才退回按距离扫描。
- **告示牌穿透 + 大箱子归一化**：准星指着箱子正面告示牌也能命中背后的箱子；命中大箱子任一半区都按完整大箱子处理。
- **界面强绑定**：打开箱子 / 木桶 / 潜影盒 / **末影箱**界面时按 `B`，目标强制为当前容器。
- **智能分类防污染（两阶段）**：阶段一只向「已有同类物品」的容器补满堆叠并占用其空槽；阶段二把全新物品**只**倒进准星锁定 / 界面绑定的容器，周边分类箱不会再被塞陌生物品。
- **GUI 双开关**（`K` 设置界面）：「准星瞄准优先」「智能分类防污染」，默认均开启，可一键回到旧手感。

### 修复

- **准星距离校验收紧**：客户端射线长度由「扫描半径」改为原版 `blockInteractionRange()`，服务端用 `isWithinBlockInteractionRange(pos, 1.0)` 复核，无法伪造远处坐标实现隔空存入。
- **快速堆叠异常回滚**：服务端处理中途抛异常时立即 `sendAllDataToRemote()` 推回权威界面状态，杜绝幽灵物品。
- **网络协议升到 v2**：`QuickStackRequest` 新增目标坐标字段；⚠️ 多人游戏请**客户端与服务端同时升级**到 1.0.2（Fabric 无协议协商，混连会断开；NeoForge 会提示「服务器未安装 OneKey」）。
- **测试**：公共内核单测 36 → 40，双加载器各跑一遍合计 **80 例全部通过**。

### 已知限制

- 快速堆叠目前只豁免**玩家背包**的锁定槽位，外部容器内的锁定槽待 v1.1「按坐标锁定」一并修复；
- 多人服中「智能分类防污染」由**服务端**配置决定，「准星瞄准优先」为客户端本地行为；
- 末影箱需打开界面才会参与（没有世界坐标，未打开时不进入范围扫描）。

## ✨ 核心特性

- ⚡ **一键整理 (`R`)**：按「分类 → 名称 → 数量」排序，空槽后置；
- 🚀 **0ms 视觉响应**：本地射线置换瞬时反馈，服务端权威无缝校准；
- 🛡️ **快捷栏严格保护**：底部 0..8 快捷栏严格不参与背包整理与快速堆叠；
- 🔒 **槽位锁定 (`Alt + 左键`)**：琥珀色描边高亮保护，世界存档独立记忆；
- 🎯 **看哪存哪 (`B`)**：准星锁定容器或当前打开的界面作为唯一目标，分类箱不再被误塞；
- 📦 **附近容器快速堆叠 (`V`)**：自动扫描周围 6 格容器，严格物品守恒；
- 🖱️ **鼠标手势增强**：Shift 双击批量同类转移、滚轮单件进出微调；
- ⚙️ **原生零依赖设置菜单 (`K`)**：无须第三方 UI 库，可视化调节所有参数；
- 🔍 **智能冲突检测**：自动检测 IPN、Mouse Tweaks、Item Scroller 等并提示。
